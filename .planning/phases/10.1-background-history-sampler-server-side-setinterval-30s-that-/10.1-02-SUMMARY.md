```typescript
export const INTERVAL_MS = 30_000
export const SAMPLER_SOURCE = 'historySamplerJob'

let handle: NodeJS.Timeout | null = null
let isRunning = false
let inFlight: Promise<void> | null = null
let inFlightStartedAt = 0                 // NEW in Wave 2 — feeds inFlightAgeMs

function deriveGameState(g: ValveLiveGame): number  // file-private, mirrors routes/live.ts
async function processMatch(g: ValveLiveGame): Promise<void>  // file-private, per-match try/catch

export async function runOnce(): Promise<void>        // never rejects
export function startSampler(): void                  // env-gated, idempotent
export async function stopSampler(): Promise<void>   // clearInterval + await inFlight
```

### runOnce flow

1. **Overlap guard (D-05):** If `isRunning` → log `warn({ inFlightAgeMs }, 'history sampler tick overlap, skipping')` and return.
2. **Mark in-flight:** `isRunning = true`, `inFlightStartedAt = Date.now()`, wrapped in `try { … } finally { isRunning = false }`.
3. **Fetch & filter:** `await getLiveLeagueGames()` (standard cached, NOT Fast — D-12); games with non-number `match_id` are filtered out; remaining games pass through `deriveGameState` and only states 5 (in-game) and 6 (finished) are kept (D-13).
4. **Fan-out (D-04):** `Promise.allSettled(active.map(processMatch))`.
5. **Per-match (D-06):** `processMatch` owns its own try/catch — state 5 → `buildSample({ scoreboard, duration, game_state: 5 })`, if non-null → `tryWriteSample(matchId, sample)`; state 6 → `deleteHistory(matchId)`. Throws are caught and logged as `error({ matchId, err }, 'history sampler match failed')` — never rethrown.
6. **Outer catch:** Any throw escaping `getLiveLeagueGames` (e.g. Valve 5xx) is caught and logged as `error({ err }, 'history sampler tick failed')` — `runOnce()` itself never rejects.

### deriveGameState (mirrors routes/live.ts lines 58-60)

```typescript
function deriveGameState(g: ValveLiveGame): number {
  if (typeof g.game_state === 'number') return g.game_state
  const radiantPlayers = g.scoreboard?.radiant?.players
  return Array.isArray(radiantPlayers) && radiantPlayers.length > 0 ? 5 : 2
}
```

Explicit `game_state` wins; otherwise infer 5 (in-game) iff scoreboard has any radiant players, else 2 (draft).

### startSampler

```typescript
if (process.env.HISTORY_SAMPLER_DISABLED === '1') { logger.info(..., 'history sampler disabled via env'); return }
if (handle) return                                  // idempotent — second call is a no-op
handle = setInterval(() => { inFlight = runOnce() }, INTERVAL_MS)
logger.info({ intervalMs: INTERVAL_MS, source: SAMPLER_SOURCE }, 'history sampler started')
```

Env check uses **exact** `=== '1'` triple-equals — no `'true'`/`'TRUE'` fallback. No `.unref()` (per Research §"Node 24 Timer & Shutdown Semantics" — letting the timer keep the loop alive is the intended shutdown signal).

### stopSampler

```typescript
if (handle) { clearInterval(handle); handle = null }
if (inFlight) {
  try { await inFlight } catch { /* runOnce already swallows + logs */ }
  inFlight = null
}
logger.info({ source: SAMPLER_SOURCE }, 'history sampler stopped')
```

The defensive try/catch around `await inFlight` is intentional — runOnce already swallows everything today, but the catch shields stopSampler if a future refactor lets something escape. The stop log fires unconditionally for operator predictability.
