## Wave 2 Hand-off

Wave 2 (Plan 02) must implement, inside the same module:

1. `runOnce()` body:
   - Outer `try/catch` around `await getLiveLeagueGames()`. On throw →
     `logger.error('history sampler tick failed')`.
   - Filter games by derivedGameState ∈ {5, 6} (mirror `routes/live.ts`
     inference: scoreboard.radiant.players non-empty → 5; explicit
     `game_state === 6` → 6).
   - `Promise.allSettled` per-match fan-out (D-04). Each per-match task is
     wrapped in its own try/catch (D-06):
     - state 5 → `buildSample(game)` then `tryWriteSample(matchId, sample)`
     - state 6 → `deleteHistory(matchId)`
     - on throw → `logger.error({ matchId, err }, 'history sampler match failed')`.
   - Skip-if-running (D-05): if `isRunning` is true on entry, compute
     `inFlightAgeMs` from a `tickStartedAt` timestamp, log
     `logger.warn({ inFlightAgeMs }, 'history sampler tick overlap, skipping')`,
     and return without doing any work. Set `isRunning = true` / `false` around
     the body.
2. `startSampler()` body:
   - If `process.env.HISTORY_SAMPLER_DISABLED === '1'` →
     `logger.info({ source: SAMPLER_SOURCE }, 'history sampler disabled via env')`
     and return.
   - If `handle` already set → return (idempotent).
   - `handle = setInterval(() => { inFlight = runOnce() }, INTERVAL_MS)`.
   - `logger.info({ intervalMs: INTERVAL_MS, source: SAMPLER_SOURCE }, 'history sampler started')`.
3. `stopSampler()` body:
   - If `handle` → `clearInterval(handle); handle = null`.
   - If `inFlight` → `await inFlight`.
   - `logger.info({ source: SAMPLER_SOURCE }, 'history sampler stopped')`.

When Wave 2 ships, all 5 tests in this file must turn green with no other
changes to `historySamplerJob.test.ts`.
