# Phase 10.1 Plan 03: Server bootstrap wire-up + graceful shutdown Summary

## One-liner

Wired `startSampler()` at server top-level and registered SIGTERM/SIGINT graceful drain that awaits `stopSampler()` then `httpServer.close()` — Phase 10.1 goal achieved end-to-end.

## What shipped

### server/src/index.ts (mutated, +25 LOC)

- Imported `startSampler, stopSampler` from `./services/historySamplerJob.js`
- Imported `logger` from `./logger.js`
- Called `startSampler()` at module top-level immediately before `serve(...)` so the loop is alive as soon as the listener binds
- Captured `const httpServer = serve(...)` for graceful close
- Defined `async function shutdown(signal: 'SIGTERM' | 'SIGINT')`: `logger.info({ signal }, 'shutdown initiated')` → `await stopSampler()` → `httpServer.close(() => process.exit(0))` → `setTimeout(() => process.exit(1), 9000).unref()` as hard-timeout safety net
- Registered both `process.on('SIGTERM', ...)` and `process.on('SIGINT', ...)` handlers
- Preserved existing `console.log('BFF listening on http://localhost:${port}')` callback verbatim
- Preserved `export default app`

### server/src/index.test.ts (new, 88 LOC)

Three GREEN lifecycle tests:
1. `startSampler` called exactly once during module import (top-level boot wiring)
2. Emitting SIGTERM triggers `stopSampler` then `httpServer.close` (via mocked `serve` close spy)
3. Emitting SIGINT triggers the same drain path

Mocks (all declared before any non-vitest import to satisfy `vi.mock` hoisting):
- `@hono/node-server` → `serve` returns `{ close: closeMock }` (close spy captured at top of file)
- `./services/historySamplerJob.js` → `startSampler`, `stopSampler` (resolves undefined), `runOnce`
- `./logger.js` → `logger.{info,warn,error}` vi.fn
- `./env.js` → static env object (bypass env validation throw)
- `./routes/live.js`, `./routes/heroes.js` → real `Hono` instances (avoid `Hono.route` undefined-map crash)
- `vi.spyOn(process, 'exit').mockImplementation(((): undefined) as never)` — prevent test-runner kill

Cleanup:
- `afterEach`: clears stopSampler / closeMock / exitSpy call history
- `afterAll`: `process.removeAllListeners('SIGTERM' | 'SIGINT')` + `exitSpy.mockRestore()`

## Deviations from Plan

### [Rule 3 - Blocking] Added test-side mocks for `./env.js` and route modules

- **Found during:** Task 2 first vitest run
- **Issue:** Importing `./index.js` in the test transitively loaded `./env.js` (which throws when UPSTASH_REDIS_URL / VALVE_API_KEY / STRATZ_TOKEN are missing in the test env) AND loaded `./routes/live.js` + `./routes/heroes.js` which then loaded valveApi/openDotaApi/stratzApi (more env reads). The plan body listed mocks for `@hono/node-server`, `./services/historySamplerJob.js`, `./logger.js` only — env + route mocks were omitted.
- **Fix:** Added three additional `vi.mock` calls before the non-vitest imports:
  - `vi.mock('./env.js', ...)` — static env object
  - `vi.mock('./routes/live.js', async () => ({ default: new Hono() }))` — returns a real Hono instance (an empty `{}` triggered `Hono.route` to call `.map` on undefined and crash)
  - `vi.mock('./routes/heroes.js', ...)` — same pattern
- **Why Rule 3 (blocking, no user permission needed):** Tests cannot pass without env + a Hono-compatible route mount; this is purely a test-infrastructure plumbing requirement, not a behavioral or architectural change.
