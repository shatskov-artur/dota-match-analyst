# Phase 10.4 Plan 01: Tactical Slate Foundation Summary

**Established the single source of truth for the Tactical Slate restyle — full Tailwind 4 @theme token layer, Google-Fonts-loaded Inter/JetBrains Mono, and a pre-emptive HistoryGraphs color migration that keeps the 105-test suite green before any Wave 1 component touches the new palette.**

## Accomplishments
- Replaced the 2-token `@theme` in `client/src/index.css` with the full Tactical Slate layer: 15 color tokens (`--color-bg`, `--color-surface`, `--color-primary`, `--color-radiant: #6bcf8a`, `--color-dire: #e06a72`, etc.), `--font-sans`/`--font-mono`, four radii, `--shadow-card`, `--tracking-label`, three prose text sizes, and the named `--breakpoint-stack: 1180px`.
- Added a plain `:root` block (NOT `@theme`, per RESEARCH Pitfall 4) for the var()-only values: soft tints, `--card-bg-grad`, `--glow-primary`, `--glow-accent` — so they resolve at runtime without generating junk utilities.
- Wired Inter (500;600) + JetBrains Mono (700;800) via a Google Fonts `<link>` with preconnect + `crossorigin` + `display=swap` (no FOIT, no npm font deps).
- Migrated HistoryGraphs to the softened team colors and updated its 6 test assertions (RED → GREEN), keeping the full suite at 105/105.

## Token utilities emitted
Every token in the `@theme` block auto-emits a runtime `var(--...)` custom property and a Tailwind utility family:
- Colors → `bg-*` / `text-*` / `border-*` / `fill-*` (e.g. `bg-bg`, `text-text-muted`, `border-border-glow`, `fill-radiant`, `text-dire`).
- Fonts → `font-sans` / `font-mono`.
- Radii → `rounded-sm` / `rounded-md` / `rounded-lg` / `rounded-full`.
- `--breakpoint-stack: 1180px` → `stack:` and `max-stack:` responsive variants, reused across Home + Match stacking thresholds.

The var()-only `:root` values (`--color-radiant-soft`, `--card-bg-grad`, `--glow-primary`, `--glow-accent`, etc.) are referenced directly as `var(--...)` by later plans and intentionally generate no utilities.

## Decisions & Deviations

### Decisions
- **const-literal, not var(), for SVG components:** HistoryGraphs keeps team colors as literal hex (`#6bcf8a` / `#e06a72`). jsdom does not resolve CSS custom properties, so asserting literal hex on `fill`/`style.color` stays deterministic. Plan 05 honors the same choice when finishing HistoryGraphs.
- **Named `stack:` breakpoint at 1180px** chosen over arbitrary inline values (Open Question 2) so the stacking threshold is reused consistently across Home + Match.

### Deviations
- **[Rule 1/3 — Blocking build error] Removed inline comments from inside the `@theme` block.** Tailwind 4 enforces "`@theme` blocks must only contain custom properties or `@keyframes`," and the initial write placed grouping comments inside the block, failing `vite build`. Fix: descriptive comments moved above the `@theme` block; the `:root` block retains its comments (allowed there). Re-verified `npm run build` green. Files: `client/src/index.css`, commit `6e30d68`.
- **[Rule 3 — Missing dependency] Installed client dependencies in the worktree.** The fresh worktree had no `node_modules`, so `tsc`/`vite`/`vitest` could not run. Ran `npm install` in the worktree root and `client/` to enable build/test verification. No `package.json`/lockfile changes were committed (deps are install-only; `node_modules` is gitignored).
