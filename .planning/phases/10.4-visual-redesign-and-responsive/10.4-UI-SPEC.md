# Phase 10.4 — UI Design Contract

> Visual and interaction contract for the "Tactical Slate" full restyle + responsive breakpoints. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Design direction is LOCKED** by sketches 003-B (Home) and 004-B (Match). Canonical tokens live at `.planning/sketches/themes/tactical-slate.css`. This phase changes the visual skin and adds responsiveness only — it does NOT change information architecture or block order (the Phase 10.3 three-row Match layout carries over).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn) |
| Preset | not applicable — Tailwind 4 CSS-first `@theme` token layer, bespoke components |
| Component library | none (hand-built React components in `client/src/components/`) |
| Icon library | none — inline SVG / CSS shapes (status dots, accent bars, map blips) |
| Font | Inter (sans + display), JetBrains Mono (numerics) — loaded via Google Fonts `<link>` in `client/index.html`, with `system-ui, sans-serif` / `ui-monospace, monospace` fallbacks |

**Why no shadcn:** The app is a restyle of existing bespoke data-viz components (ScoreHeader, HistoryGraphs, DotaMapView, etc.), not a generic CRUD UI. No component primitives are being added. UI-01 mandates a shared token layer, satisfied by Tailwind 4 `@theme` tokens, not a registry. Registry safety gate: not applicable. No third-party registries declared.

**Token migration mandate (UI-01):** Components today hardcode hex literals (e.g. `style={{ background: '#0a0a0a', color: '#d8d8d8' }}` in `MatchPage.tsx`, `--color-radiant: #4ade80` in `index.css`). Every component listed in the Component Inventory MUST consume the tokens below — no inline hex literals may remain after this phase. Tokens are declared once in `client/src/index.css` under `@theme` (Tailwind 4 generates `bg-*`, `text-*`, `border-*` utilities from them) and as CSS custom properties for cases that need raw `var(--…)` (SVG `fill`/`stroke`, gradients, box-shadows).

## Spacing Scale

The spacing scale below contains ONLY standard-set layout values: **4, 8, 16, 24, 32, 48, 64** (all multiples of 4). Map these to Tailwind 4 spacing utilities. Fixed off-grid element/glyph dimensions are documented separately in the next table — they are not layout spacing and are intentionally excluded from this scale.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Item-slot gaps, building tier dot gaps, accent-bar width |
| sm | 8px | Compact element spacing, player-row vertical gap, status-dot gaps |
| md | 16px | Default element spacing, card-label bottom margin, win-prob row gap, phone card padding, phone horizontal gutters |
| lg | 24px | Card padding (`22px 24px` → standardize to 24px), grid gaps between cards (Row 1 / Row 2), section padding, desktop/tablet horizontal gutters |
| xl | 32px | Major section breaks |
| 2xl | 48px | Large vertical separators |
| 3xl | 64px | Page-level vertical rhythm (rare) |

**Card padding contract:** `24px` (lg) desktop/laptop → `16px` (md) on phone (≤640px) to reclaim width for dense panels.
**Card-grid gaps:** Row 1 / Row 2 inter-card gaps use `24px` (lg) — snapped from the sketch's `20px` to the standard set so the scale stays clean.
**Page gutters:** Home `max-width: 1180px`, Match `max-width: 1320px`, both centered; horizontal padding `24px` (lg) desktop/tablet → `16px` (md) phone.

### Fixed Element / Data-Glyph Dimensions (not layout spacing)

These are fixed SVG/element sizes for decorative rails and data glyphs. They are intentionally off the spacing scale — they describe element dimensions, not layout rhythm, and are exempt from the standard-set spacing rule.

| Element | Fixed size | Notes |
|---------|-----------|-------|
| Match-row hover accent rail | 3px wide | Decorative left rail (SVG/border element), not spacing |
| Win-prob track height | 9px | Fixed data-glyph (bar track) |
| Building-tier dot | 9px | Fixed data-glyph (status dot) |
| Map blip | 12px | Fixed data-glyph (positional marker) |

**Touch target:** Minimum interactive touch target on phone = `44px` height for tappable rows (league header, match row) per touch-accessibility guidance. 44px is a multiple of 4 and remains in-spec.

## Typography

Inter for all prose; JetBrains Mono for every numeric (scores, clocks, K/D/A, net worth, gold diff, timers, win-prob values) with `font-variant-numeric: tabular-nums`. The prose scale below is **exactly 4 sizes and exactly 2 weights**. Numeric/mono display glyphs are a separate, out-of-scale system documented in their own subsection and are NOT counted toward the prose limits.

### Prose scale (Inter) — exactly 4 sizes, exactly 2 weights

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|
| Label | 11px | 600 (semibold) | 1.2 | Uppercase, `letter-spacing: 0.14em` (`--tracking-label`); card-labels, section labels, team tags, status captions. Color `--color-text-dim`. The data-delay disclosure caption renders at this Label size (folded in — no separate 10px step). |
| Body | 14px | 500 (medium) | 1.5 | Player names, item owner labels, cooldown labels, series text. Panel-level override: dense Match panels may render Body at 13px as a context override of this same role — NOT a separate scale step. |
| Heading | 20px | 600 (semibold) | 1.2 | Card section heads, brand sub-row. Panel-level override: the league-name renders at 16px as a context override of this same Heading role — NOT a separate scale step. |
| Display | clamp(1.8rem, 4vw, 2.8rem) | 600 (semibold) | 1.0 | Match-page `h1` title (team vs team), pure white `#fff`, `-0.02em` tracking. |

**Prose weight rule:** Prose uses exactly two weights — 500 (medium) and 600 (semibold). No other weight appears in Inter prose.

### Numeric / Mono Display (JetBrains Mono)

**Out-of-scale data glyphs on JetBrains Mono — NOT counted toward the 4-size / 2-weight prose limit.** These are numeric data displays, not text in the prose hierarchy.

| Glyph | Size | Weight | Notes |
|-------|------|--------|-------|
| Kill score | 56px desktop → 44px tablet → 40px phone | 800 | Responsive per the Match-page reflow section; mono-numeric display weight, not a prose weight |
| Gold-diff value | matches surrounding scoreline context | 700 | mono-numeric display weight, not a prose weight |
| Cooldown timer | 15px | 700 | Steel (`--color-accent`); mono-numeric display weight, not a prose weight |
| Numeric floor (K/D/A, net worth, win-prob values) | 12px minimum — never smaller | 700 | `tabular-nums` always on for column alignment; mono-numeric display weight, not a prose weight |

**Mono display weights:** 700 and 800. These are mono-numeric display weights, NOT prose weights, and do not count against the 2-weight prose constraint.

**Tracking (prose):** Uppercase labels `0.14em` (`--tracking-label`); status tags `0.16em`; back-link `0.22em`. Body/Heading prose: default. Display `h1`: `-0.02em`.

## Color

60 / 30 / 10 split applied to the Tactical Slate palette.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#14151a` (`--color-bg`) | App background — the warm charcoal field everything floats on |
| Secondary (30%) | `#1d1f27` / `#23262f` (`--color-surface` / `--color-surface-2`) on `--card-bg-grad` | Cards, league panels, hover rows, item slots, map field |
| Accent (10%) | `#d4a24a` (`--color-primary`, gold) + `#5b9bd5` (`--color-accent`, steel) | See reserved-for list |
| Destructive | `#e06a72` (`--color-danger`, shares Dire red) | Error banners only |

**Gold accent (`--color-primary`) reserved for:**
- Net-worth values and gold-diff number (`--color-gold`)
- History-chart headline lead value when Radiant leads (chart highlight)
- Card-label accent bar (the 3px gold tick before each card title)
- League "Premium" tier badge
- Item-slot "filled" state highlight
- Hover rail on Home match rows (left 3px bar)
- Logo mark glyph + brand wordmark
- Roshan loot-drop filled slot

**Steel accent (`--color-accent`) reserved for:**
- Cooldown timer numerics
- Roshan timer pill in score header
- League "Pro" tier badge
- Win-prob "Stratz" row emphasis (label only — bar fills stay team-colored)

**Team colors (`--color-radiant` / `--color-dire`) reserved for team identity ONLY:** team tags, kill scores, win-prob bar fills, player-row portrait outlines, map blips, building tier dots, history-chart line/fill, status `Live` (Dire red) / `Draft` (gold) tags. Never use team colors for generic UI chrome.

**Rule:** Accent (gold + steel) must stay ≤ ~10% of any screen's visual weight. Team colors are functional data, counted separately. No accent on generic borders, generic text, or non-semantic backgrounds.

## Responsive Breakpoint Contract (UI-02 / UI-03)

Four target widths. **Hard constraint for all four: no horizontal scroll, no overlap, no clipping.** Mobile-first reflow — define each screen's behavior at each width. The Phase 10.3 block order and information architecture are preserved at every width; only column count and sizing change.

### Breakpoint tokens (map to Tailwind 4 defaults)

| Name | Width | Tailwind |
|------|-------|----------|
| Phone | ~375px (base, 320–639px) | base / `max-sm` |
| Tablet | ~768px (640–1023px) | `sm` / `md` |
| Laptop | ~1280px (1024–1439px) | `lg` / `xl` |
| Desktop | ~1536px+ (≥1440px) | `2xl` |

Single design breakpoint that flips dense grids to stacked: **`max-width: 1180px` → single column** (this is the existing `.row2` breakpoint in sketch 004 — adopt it as the canonical "stack" threshold). Phone-specific tightening at **`max-width: 640px`**.

### Home page reflow

| Element | Desktop / Laptop (≥1024px) | Tablet (640–1023px) | Phone (≤639px) |
|---------|----------------------------|---------------------|----------------|
| Header (logo + brand + live pill) | One row, `live-pill` pushed right via `margin-left:auto` | Same single row | Logo + brand on one row; `live-pill` wraps below brand OR shrinks (hide "now" word, keep `• 7 live`) — never overflow |
| League panel | Full-width card, max-width 1180px | Full-width, 24px gutters | Full-width, 16px gutters, `radius-md` instead of `radius-lg` to save edge space |
| League header (tier + name + count) | One row | One row | Tier badge + name on one row; count drops to a second line if name truncates; min 44px tap height |
| **Match row** (currently `grid-template-columns: 1fr auto auto auto` = teams \| kills \| series \| status+clock) | 4-column grid as-is | 4-column grid as-is | **Collapse to 2 rows inside the row:** Row A = teams (full width, team names may truncate with ellipsis); Row B = kills + series + status+clock in a single flex line (`gap: 16px`, wrap allowed). Use `grid-template-columns: 1fr; gap: 8px` and nest the metadata in a flex row. Keep team logos at 26px; never clip team names — truncate with `text-overflow: ellipsis`. |

### Match page reflow

| Block | Desktop / Laptop (≥1180px) | Tablet (640–1179px) | Phone (≤639px) |
|-------|----------------------------|---------------------|----------------|
| `h1` title | `clamp(1.8rem,4vw,2.8rem)` | clamp scales down | clamp floor 1.8rem; allow wrap to 2 lines |
| **Score header** (3-col grid `1fr auto 1fr`: Radiant \| center meta \| Dire) | 3-col grid; kill score 56px | 3-col grid; kill score 44px | **Stack to 3 rows:** Radiant side (tag + kill + series) → center meta (status, clock, roshan, gold diff, delay) as a wrapping flex row → Dire side. Right-align Dire side becomes left-align when stacked. Kill score 40px. Center meta items wrap, never overflow. |
| **Win-prob bars** | Full-width rows (`lbl 52px` + track + `wpval 78px`) | Same | Same; if `wpval` + `lbl` crowd the track on 320px, shrink label to icon/abbrev but keep the track ≥ 120px wide |
| **Row 1** (heroes \| items \| cooldowns — `1fr 1fr 1fr`) | 3-col, equal width, `items-stretch`, gap 24px | **2-col:** heroes + items side by side (`1fr 1fr`); cooldowns full-width below. OR stack all three if 768px is too tight for 2 — prefer 2-col at ≥768px, stack at <768px | **1-col stack** in order: Heroes & players → Net worth & items → Ultimates on cooldown. Each card full width. |
| **Row 2** (history \| roshan+buildings 320px \| map 420px — `1fr 320px 420px`) | 3-col as-is | **1-col stack** (adopt existing `@media (max-width:1180px){grid-template-columns:1fr}`): history chart (full width) → roshan+buildings stack (full width, no longer 320px-capped) → map. **Map drops its fixed 420px:** becomes `width: 100%; max-width: 420px; aspect-ratio: 1; margin: 0 auto` so it never forces horizontal scroll on tablet/phone. | Same 1-col stack; map `max-width: 100%` centered, still `aspect-ratio: 1`; roshan + buildings stack vertically |

### Dense-data legibility on phone (UI-03 — non-negotiable)

- **Hero portraits:** keep 40×28px (player grid) / 32×22px (items row) — do not shrink below these; they stay readable at 375px. Keep Radiant/Dire outline rings.
- **6 item slots per player:** keep 26×26px slots with 4px gap (6×26 + 5×4 = 176px) — fits within a phone card at 16px padding. Do NOT reduce slot count or wrap slots; if width is truly constrained, the owner-name column (`who`, 66px) may shrink to 48px with ellipsis before the slots shrink.
- **Cooldown icons:** keep 42×30px ult icon; timer stays 15px mono steel. The `who` label flexes/truncates first.
- **Numerics:** never drop below 12px for K/D/A and net worth; tabular-nums always on so columns align.
- **Map blips:** keep 12px; on a smaller phone map they may overlap slightly — acceptable, but the map itself must not overflow its card.

## Interaction Contract

Carry forward the validated "prefer passive over interactive" principle from the sketch-findings skill.

| Interaction | Behavior |
|-------------|----------|
| Match-row hover (Home) | Left 3px gold rail fades in + row bg → `--color-surface-2`. No glow on the rail (Tactical Slate variant override: `box-shadow: none`). Transition 140ms ease. |
| Player / item / cooldown row hover (Match) | Row bg → `--color-surface-2`, 120ms. |
| League header | Click toggles accordion (existing behavior preserved). Cursor pointer, 44px min tap height. |
| Back link (Match) | Color → `--color-primary` on hover, 160ms. |
| Charts | **No hover tooltips.** Static peak labels only (per charts-data-viz reference). |
| Live status dot | `pulse 1.6s infinite` opacity animation (existing). |
| Touch | All hover affordances must have a non-hover resting state that is fully legible (hover is enhancement only, never required to read data). |

## Copywriting Contract

This phase is a restyle — most strings are pre-existing. Confirmed/standardized copy below; tone is terse, data-broadcast, no decoration.

| Element | Copy |
|---------|------|
| Primary CTA | No traditional CTA. The primary action is opening a match: match rows are the affordance. Home back-affordance on Match page reads **"← Back to matches"**. |
| Home header live indicator | **"{N} live now"** (e.g. "7 live now") with pulsing dot |
| Section label (Home) | **"Live matches"** (uppercase, tracked) |
| Empty state heading (Home, no live matches) | **"No live matches right now"** |
| Empty state body (Home) | **"Pro tournament games appear here as they go live. This page refreshes every 30 seconds."** |
| Empty state (Match, pre-game / draft) | Existing draft/skeleton UI carries over — no new copy. |
| Error state | **"Couldn't load live matches."** body: **"We'll keep retrying automatically. Check your connection if this persists."** (Match page: "Couldn't load this match.") — rendered in `ErrorBanner` styled with `--color-danger`. |
| Data-delay disclosure (Match score header) | **"~120s delay"** (existing) — `--color-text-dim`, rendered at the 11px Label size |
| Destructive confirmation | **None.** This is a read-only analytics app — no destructive actions exist in this phase. |
