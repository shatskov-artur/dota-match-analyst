# Phase 10.4 Plan 03: Match Score Region Retoken + Responsive Summary

**Migrated the Match score region (sketch 004-B) to Tactical Slate tokens with zero color-hex literals: ScoreHeader gains responsive kill scores (40/44/56px), a steel roshan pill, gold-diff in --color-gold, and a phone 3-row stack; WinProbBar gains a dire-soft track with team-colored fills, mono values, and a 120px min track — both keep all existing self-gating and formatting logic and the 105-test suite stays green.**

## What Was Built

### Task 1 — ScoreHeader retoken + responsive
- All inline-style hexes replaced with Tactical Slate tokens:
  - Radiant team tag `#4ade80` → `var(--color-radiant)`; Dire tag `#ef4444` → `var(--color-dire)`; both at `tracking-[0.16em]` (UI-SPEC status-tag tracking).
  - Kill scores: `text-[52px]` + inline white → `text-[40px] md:text-[44px] lg:text-[56px] font-mono font-extrabold tabular-nums leading-none text-text` (phone 40 → tablet 44 → laptop+ 56).
  - Series score `#666666` → `text-text-dim`; game clock `#888888` → `text-text-muted`.
  - Roshan pill `#f97316` + rgba tints → `color var(--color-accent)`, `background var(--color-accent-soft)`, `borderColor var(--color-accent)` with `border` class (UI-SPEC: steel roshan pill).
  - Gold-diff value overridden to `var(--color-gold)` (keeps `goldDiff.text`).
  - Delay disclosure `#555555` → `text-text-dim`, rendered at the 11px Label size (`text-[11px] uppercase tracking-label`).
  - Score row border `#1a1a1a` inline → `border-b border-border` class.
- Phone 3-row stack: outer row `flex flex-col gap-4 md:flex-row md:items-center md:justify-between`; Dire side `items-start md:items-end`; `min-w-0` on both team-tag columns to prevent overflow.
- All logic preserved: NW reduction, getStatusLabel, formatDuration, StatusTag, tabular-nums.

### Task 2 — WinProbBar retoken
- Source label `#888888` → `text-text-muted`; percent values `#4ade80`/`#ef4444` → `var(--color-radiant)`/`var(--color-dire)` with `font-mono` added per UI-SPEC mono-values.
- Track `#0f0f0f` → `var(--color-dire-soft)`; gradient `#4ade80`/`#ef4444` → `var(--color-radiant)`/`var(--color-dire)`. Height/borderRadius/transition kept inline (non-color); prefers-reduced-motion logic preserved.
- Panel border `#1a1a1a` inline → `border-b border-border` class.
- `min-w-[120px]` added to the flex-1 track so it never collapses on 320px phones (UI-SPEC: keep track ≥ 120px).
- Self-gate (`gameState !== 5 || (gameDuration ?? 0) <= 300` → null) and Stratz-null conditional left exactly intact.
