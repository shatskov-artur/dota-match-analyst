Add per-upstream rate-limit queues + 429 exponential backoff + stale-cache-on-exhaustion + structured throttle logging to the BFF's single upstream chokepoint, `cached()`. Satisfies ROADMAP criterion 2.

    // Parse Retry-After: integer seconds OR an HTTP-date. Returns ms or null.
    function parseRetryAfter(res: Response): number | null {
