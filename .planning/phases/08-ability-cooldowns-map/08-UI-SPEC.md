### MatchPage Layout Restructure (D-01)

Two-column layout replaces the current separate items row + map row.

```
┌─────────────────────────────────┬──────────────────────────────┐
│  Left column (flex-col)         │  Right column (flex-col)     │
│  ─────────────────────────      │  ────────────────────────    │
│  HeroPlayerGrid                 │  DotaMapView (320×320)       │
│  (existing, unchanged)          │  + hero position circles     │
│                                 │                              │
│  ItemsBlock                     │  CooldownsBlock              │
│  (existing, unchanged)          │  (new — flex-1)              │
└─────────────────────────────────┴──────────────────────────────┘
```

- Container: `flex gap-4` (16px gap)
- Left column: `flex flex-col flex-1`
- Right column: `flex flex-col` (width fixed at 320px to match map)
- BuildingsSection: placed in a full-width row **below** the two-column block (no column constraint)
- Both columns hidden when `game_state !== 5` or scoreboard absent

### DotaMapView Extension

New optional prop: `heroPositions?: HeroPosition[]`

```ts
interface HeroPosition {
  hero_id: number
  team: 'radiant' | 'dire'
  x_pos: number   // Valve coordinate ~0–16384
  y_pos: number   // Valve coordinate ~0–16384, y=0 is top
}
```

Coordinate normalization (SVG 320×320):
```
svgX = (x_pos / 16384) * 320
svgY = (1 - y_pos / 16384) * 320   // y-axis flipped: Valve y=0 is Dire base (top of minimap)
```

Hero circle rendering per position (layered SVG elements):
1. `<defs><clipPath id="cp-{hero_id}"><circle cx={svgX} cy={svgY} r={8}/></clipPath></defs>`
2. `<image href={portraitUrl} x={svgX-8} y={svgY-8} width={16} height={16} clipPath="url(#cp-{hero_id})" />`
3. `<circle cx={svgX} cy={svgY} r={8} fill="none" stroke={teamColor} strokeWidth={1.5}/>`

- Circle radius: 8px (16px diameter)
- Portrait URL: same CDN pattern as HeroPlayerGrid — `heroMapper(hero_id).portrait`
- Stroke color: `#4ade80` (Radiant) or `#ef4444` (Dire), strokeWidth 1.5
- When `heroPositions` is undefined or empty: map renders as before (buildings only)
- Heroes rendered **above** building dots in SVG z-order (appended after building elements)

### CooldownsBlock

```ts
interface CooldownEntry {
  hero_id: number
  team: 'radiant' | 'dire'
  ultimate_state: number    // 0=unavailable/dead, 2=on cooldown, 3=charging
  ultimate_cooldown: number // seconds remaining
}
```

Render logic:
- Filter: `players.filter(p => p.ultimate_state !== 1)` — exclude "ready" heroes
- Sort: ascending by `ultimate_cooldown` (shortest remaining first)
- If filtered list is empty → component returns `null` (unmounted, no empty state)

Section header: `"Cooldowns"` — matches ItemsBlock/HeroPlayerGrid header style.

Row layout (min-height 44px, border-bottom #1e1e1e):
```
[hero portrait 32px] [ability icon 32px] [countdown] [state label]
gap: 8px between each cell
```

- **Hero portrait**: 32×32px `<img>` via `heroMapper(hero_id).portrait`, `object-fit: cover`, `border-radius: 4px`
- **Ability icon**: 32×32px from `https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/abilities/{ult_name}.png`
  - Source: `heroUltimates[hero_id]` from `shared/heroUltimates.json`
  - If unknown: 32×32 dark placeholder `#1a1a1a bg + #2a2a2a border + border-radius 4px`
  - `onError` fallback same as ItemSlot pattern
- **Countdown**: `14px bold tabular-nums #e8e8e8` number + `"s"` suffix in `12px #555555`
  - `ultimate_state === 0` (hero dead): show `"—"` in `#555555` instead of number
- **State label** (only when applicable):
  - `ultimate_state === 3`: `"charging"` in `10px #555555`
  - `ultimate_state === 0`: `"unavail"` in `10px #555555`
  - `ultimate_state === 2` (plain cooldown): no label

Row hover: background transitions to `#0f0f0f` (160ms ease) — same as ItemsBlock.

CooldownsBlock has `flex-1` so it expands to fill remaining right-column height below the map.
