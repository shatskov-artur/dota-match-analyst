# Phase 10.3 Plan 01: MatchPage in-game branch 3-row restructure (sketch 002-C) Summary

## One-liner

MatchPage in-game branch refactored from legacy 2-column + 320px right-stack layout into sketch-002-C three stacked rows: heroes/items/cooldowns (3×flex-1), map/roshan (2×flex-1), buildings/history (2×flex-1).

## Before / After Structure

**Before (10.2-03 shape):**
- Outer: `mt-12 flex gap-12 items-stretch` with 3 children
  - HeroPlayerGrid
  - `w-fit` ItemsBlock wrapper
  - `flex flex-col gap-8 shrink-0 w-[320px] h-full` right column containing DotaMapView wrapper / RoshanBlock / CooldownsBlock
- Standalone `<div className="mt-12">` BuildingsSection (gated by `!buildings.unavailable`)
- Standalone `<section style={{ marginTop: 16 }}>` HistoryGraphs

**After (10.3-01 sketch 002-C):**
- Outer: `mt-12 flex flex-col gap-12` containing 3 rows
- Row 1 (`flex gap-8 items-stretch`): 3 children, each `flex-1 min-w-0` — HeroPlayerGrid | ItemsBlock | CooldownsBlock
- Row 2 (`flex gap-8 items-stretch`): 2 children, each `flex-1 min-w-0` — DotaMapView (with `flex items-start justify-center` slot wrapper) | RoshanBlock
- Row 3 (`flex gap-8 items-stretch`): 2 children, each `flex-1 min-w-0` — BuildingsSection (or `aria-hidden` placeholder div when `buildings.unavailable`) | HistoryGraphs

Pre-game branch (`!(game_state===5 && radiantPlayers.length>0)`) untouched: HeroPlayerGrid alone in `<div className="mt-12">`.
