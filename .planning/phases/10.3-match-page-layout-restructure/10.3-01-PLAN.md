```tsx
      {/* In-game three-row layout (sketch 002-C).
          Row 1 (3×flex-1, items-stretch): HeroPlayerGrid | ItemsBlock | CooldownsBlock — equal width and height.
          Row 2 (2×flex-1, items-stretch): DotaMapView | RoshanBlock — 50/50 split.
          Row 3 (2×flex-1, items-stretch): BuildingsSection | HistoryGraphs — 50/50 split.
            When buildings.unavailable, a transparent placeholder div holds the left slot so HistoryGraphs
            still occupies the right half (preserves 50% chart width across pre/post tower-state availability).
          DotaMapView responsive SVG (10.2-03) carries over unchanged.
          CooldownsBlock root (`flex flex-col flex-1 min-h-0 overflow-y-auto`, 10.2-03) carries over unchanged.
          RoshanBlock root (`flex flex-col flex-1`) carries over unchanged. */}
      {match?.game_state === 5 && radiantPlayers.length > 0 && (
        <div className="mt-12 flex flex-col gap-12">
          {/* Row 1 — heroes / items / cooldowns */}
          <div className="flex gap-8 items-stretch">
            <div className="flex-1 min-w-0">
              <HeroPlayerGrid
                radiantPlayers={radiantPlayers}
                direPlayers={direPlayers}
                isLoading={isLoading}
                playerIntelMap={playerIntelMap}
              />
            </div>
            <div className="flex-1 min-w-0 flex flex-col">
              <ItemsBlock
                players={[
                  ...radiantPlayers.map(p => ({ ...p, team: 'radiant' as const })),
                  ...direPlayers.map(p => ({ ...p, team: 'dire' as const })),
                ].sort((a, b) => ((b.net_worth as number | undefined) ?? 0) - ((a.net_worth as number | undefined) ?? 0))}
              />
            </div>
            <div className="flex-1 min-w-0 flex flex-col">
              <CooldownsBlock
                players={[
                  ...radiantPlayers.map(p => ({ ...p, team: 'radiant' as const })),
                  ...direPlayers.map(p => ({ ...p, team: 'dire' as const })),
                ]}
              />
            </div>
          </div>

          {/* Row 2 — map / roshan */}
          <div className="flex gap-8 items-stretch">
            <div className="flex-1 min-w-0 flex items-start justify-center">
              <DotaMapView
                buildings={buildings}
                heroPositions={[
                  ...radiantPlayers
                    .filter(p => typeof p.position_x === 'number' && typeof p.position_y === 'number' && typeof p.hero_id === 'number')
                    .map(p => ({
                      hero_id: p.hero_id as number,
                      team: 'radiant' as const,
                      position_x: p.position_x as number,
                      position_y: p.position_y as number,
                    })),
                  ...direPlayers
                    .filter(p => typeof p.position_x === 'number' && typeof p.position_y === 'number' && typeof p.hero_id === 'number')
                    .map(p => ({
                      hero_id: p.hero_id as number,
                      team: 'dire' as const,
                      position_x: p.position_x as number,
                      position_y: p.position_y as number,
                    })),
                ]}
              />
            </div>
            <div className="flex-1 min-w-0 flex flex-col">
              <RoshanBlock roshan={match?.roshan ?? null} />
            </div>
          </div>

          {/* Row 3 — buildings / history */}
          <div className="flex gap-8 items-stretch">
            <div className="flex-1 min-w-0 flex flex-col">
              {!buildings.unavailable ? (
                <BuildingsSection buildings={buildings} />
              ) : (
                <div aria-hidden="true" />
              )}
            </div>
            <div className="flex-1 min-w-0 flex flex-col">
              <HistoryGraphs
                history={history}
                gameDuration={match?.duration}
                gameState={match?.game_state}
              />
            </div>
          </div>
        </div>
      )}
```

Notes on the change:
- `gap-12` on the outer column matches the previous between-section vertical rhythm (was `mt-12` between blocks).
- `gap-8` between row children matches sketch 002-C horizontal spacing.
- `min-w-0` on every flex-1 wrapper is the standard Tailwind workaround that prevents flex children from refusing to shrink below their intrinsic content width (especially important for ItemsBlock and HistoryGraphs SVG).
- The DotaMapView wrapper keeps `flex items-start justify-center` so the responsive aspect-square SVG sits at the top of the slot and centers when the slot is wider than tall. The 10.2-03 hotfix is preserved — only the parent slot changed, not DotaMapView itself.
- The placeholder `<div aria-hidden="true" />` in Row 3 keeps the 50/50 split when buildings.unavailable; without it, HistoryGraphs would expand to full width and the layout would visually jolt the moment building data arrives.
- DO NOT touch the pre-game branch (lines ~100-110 — `!(match?.game_state === 5 && radiantPlayers.length > 0) && <div className="mt-12"><HeroPlayerGrid ... /></div>`).
- After deletion of the two obsolete sections, the file ends with `</div>` (the outer min-h-screen container) immediately after this new in-game block.
- Imports remain unchanged — all eight component imports stay.
