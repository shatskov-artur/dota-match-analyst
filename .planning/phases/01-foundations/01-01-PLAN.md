<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → BFF | Vite dev proxy forwards /api/* to localhost:3001; production will use a public URL |
| BFF → external APIs | Outbound fetch to Valve, OpenDota, Stratz; responses parsed through zod |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `.env` containing API keys | mitigate | `.gitignore` excludes `.env`; `.env.example` committed with placeholder values only |
| T-01-02 | Spoofing | CORS on Hono server | mitigate | `cors({ origin: 'http://localhost:5173' })` restricts dev origin; production origin locked in Phase 7 deploy config |
| T-01-03 | Tampering | External API responses (Valve/OpenDota) silently changing schema | mitigate | All external responses parsed through zod `.passthrough()` schemas — enforced in Plan 05 |
</threat_model>
