<objective>
Phase 10.2 Wave 3 — equalize the in-game right column so RoshanBlock + CooldownsBlock fill the column height alongside the fixed 320×320 DotaMapView, matching the visual height of the sibling HeroPlayerGrid column.

Purpose: Current behavior (`MatchPage.tsx:134`) sets `style={{ width: 320 }}` on the right-column wrapper with no height context. The outer row at line 117 already has `items-stretch` and HeroPlayerGrid drives the row height, but the right-column wrapper itself has intrinsic column height (sum of children), so its `flex-1`-declaring children (RoshanBlock root, CooldownsBlock root) have no parent height to expand into. The fix is two-fold: (1) Add `h-full` (plus convert inline width to Tailwind class) on the right-column wrapper so it stretches to the row's stretched height; (2) Add defensive `min-h-0 overflow-y-auto` to CooldownsBlock so a tall cooldown list scrolls inside its allocated `flex-1` space instead of overflowing the column. DotaMapView's pixel-fixed 320×320 SVG MUST NOT stretch (Pitfall 3: hero ring positions would drift) — `shrink-0` on the wrapper combined with DotaMapView's own intrinsic `width={320} height={320}` keeps it locked.

Output: One className change in `MatchPage.tsx:134`; one className addition in `CooldownsBlock.tsx:87`.
</objective>
