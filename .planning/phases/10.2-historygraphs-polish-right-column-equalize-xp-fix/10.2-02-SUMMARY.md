# Phase 10.2 Plan 02: HistoryGraphs sketch-001-C rewrite Summary

Near-total rewrite of `HistoryGraphs.tsx` per sketch 001 winner C — replaces ~80 lines of hover infrastructure (HoverState, useRef wrapper, mouseMove/mouseLeave handlers, tooltip JSX) with static peak labels, a headline value colored by leading side, and a sketch-verbatim panel chrome upgrade. Companion test file wiped and replaced with 13 RTL tests covering UAT-CHART-01..06 using relative geometry assertions only (no `yMid=74` magic constants).

## Removed surfaces

- `HoverState` interface
- `useRef` for wrapper element
- `onMouseMove` / `onMouseLeave` handlers
- Tooltip JSX (full overlay block + projection line + dot + label group)
- `formatK` helper (replaced by signed `fmtVal` + inline headline math)
- File-top color constants `HOVER_LINE`, `TOOLTIP_BG`, `TOOLTIP_BORDER`
- `ChartGeometry` interface and its hover-driven projection logic
- Test helper `mockBCR` (no mouseMove projection tests means no need to mock getBoundingClientRect)
- Magic-constant test against `yMid=74` (replaced by relative-margin assertion `yOfMax > PAD_TOP + 8`)

## Added surfaces

- `ChartSection` (private to file): pure-render component taking `samples`, `pick`, `label`
- `SkeletonHistoryBlock` (private): isolates the 1Hz tick `useState` + `useEffect` so the parent has no hooks before its early return (rules-of-hooks compliance)
- `fmtVal(v: number)`: signed value formatter — `+3.4k` / `-1.2k` / `+42`
- `fmtMmSs(seconds: number)`: zero-padded `M:SS` formatter
- Static peak detection: single-pass loop finding `rPeak = max(v > 0)` and `dPeak = min(v < 0)` per section
- Edge-anchor clamp helper: `anchorFor(px)` returns `'start' | 'middle' | 'end'` based on `px < 80` / `> W - 80`
- New geometry constants: `W = 1000`, `H = 200`, `PAD_TOP = 28`, `PAD_BOTTOM = 22`, `INNER_H = 150`, `MID_Y = 103` (replacing old `W=640, H=160, PAD_L=40, PAD_R=12, PAD_T=12, PAD_B=24` — bigger viewport per sketch)
- Headline value spans (`<span>` absolute-positioned top-right per section) — `Radiant +X.Xk` or `Dire +X.Xk` colored by side
- Section labels (`<span>` absolute-positioned top-left) — `Gold lead` / `XP lead` in uppercase tracking 0.18em
