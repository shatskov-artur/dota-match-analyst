# Phase 10.2 Plan 03: Right-column equalize + CooldownsBlock overflow hardening Summary

Equalized the in-game right column (DotaMapView + RoshanBlock + CooldownsBlock) to HeroPlayerGrid height via `h-full` + `shrink-0` Tailwind classes on the wrapper, and added defensive `min-h-0 overflow-y-auto` to CooldownsBlock so tall ult lists scroll inside the flex-1 allocation instead of blowing out the column.

## Changes

### Task 1: `client/src/pages/MatchPage.tsx`

Single-line className change at line 134:

```diff
-          <div className="flex flex-col gap-8" style={{ width: 320 }}>
+          <div className="flex flex-col gap-8 shrink-0 w-[320px] h-full">
```

- Inline `style={{ width: 320 }}` fully removed.
- `shrink-0` prevents flex shrink under sibling pressure (locks 320px width).
- `w-[320px]` replaces the inline width via Tailwind arbitrary value.
- `h-full` resolves to row height because the outer row (line 117) already had `items-stretch`. Now RoshanBlock + CooldownsBlock's existing `flex-1` finally has a height context to expand into.
- Children (DotaMapView, RoshanBlock, CooldownsBlock) and their props are untouched.
- Outer row, middle column, BuildingsSection, HistoryGraphs section: untouched.

Commit: `c4697bf` — `feat(10.2-03): equalize right-column via h-full + shrink-0`

### Task 2: `client/src/components/CooldownsBlock.tsx`

Single-line className change at line 87:

```diff
-    <div className="flex flex-col flex-1">
+    <div className="flex flex-col flex-1 min-h-0 overflow-y-auto">
```

- `min-h-0` is the critical addition — flex items refuse to shrink below intrinsic content size by default; without this, a tall cooldown list would expand the parent column rather than scroll.
- `overflow-y-auto` activates a scrollbar only when content overflows (common case ≤6 ults shows no scrollbar).
- The 1Hz `setInterval(() => setNow(Date.now()), 1000)` tick (lines 58–61) is preserved verbatim per project memory `feedback_cooldown_ticking.md`.
- Content-signature ref guard (`sigRef` + `referenceRef`), `active` mapping/filter/sort, empty-state early return (`if (active.length === 0) return null`), and row-rendering JSX (heroInfo portrait, UltSlot, countdown number/ready badge) — all preserved verbatim.

Commit: `bd8ddc2` — `feat(10.2-03): defensive overflow on CooldownsBlock`
