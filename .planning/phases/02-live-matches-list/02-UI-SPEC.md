## Spacing Scale

Declared values (multiples of 4, Tailwind 4 defaults — no custom overrides needed):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`p-1`, `gap-1`) | Icon gaps, tag padding inline |
| sm | 8px (`p-2`, `gap-2`) | Tag vertical padding, row cell internal gap |
| md | 16px (`p-4`, `gap-4`) | Row horizontal padding, accordion header padding |
| lg | 24px (`p-6`, `gap-6`) | Page-level section padding |
| xl | 32px (`p-8`) | Page top/bottom padding |
| 2xl | 48px | Major layout separation (header from list body) |
| 3xl | 64px | Not used in Phase 2 |

Exceptions:
- Match row height: 44px minimum (touch-target minimum; desktop-first but good practice).
- Accordion section header height: 40px.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm font-normal` |
| Label | 12px | 400 (regular) | 1.4 | `text-xs font-normal` |
| Heading | 20px | 700 (bold) | 1.2 | `text-xl font-bold` |
| Display | 28px | 700 (bold) | 1.2 | `text-2xl font-bold` |

Rules:
- Match row team names: Body (14px / 400).
- Series score and game duration: Label (12px / 400) — de-emphasized relative to team names.
- Accordion section (league) header: Heading (20px / 700).
- Page title "Dota 2 Match Analyst": Display (28px / 700).
- Last-updated timestamp: Label (12px / 400).
- Status tag text: Label (12px / 400).

Source: Extrapolated from established `App.tsx` pattern (`text-2xl font-bold` for heading). 4 sizes maximum enforced. Weights collapsed to 2 (400 regular, 700 bold) per design contract rule.

## Component Inventory

All components are hand-built with Tailwind utilities. No external component library.

### 1. `<StatusTag>`
- Shape: rounded pill, `rounded-full`
- Padding: `px-2 py-1` (8px horizontal, 4px vertical)
- Typography: Label (12px / 400) — `text-xs font-normal`
- Colors: per status tag color map above
- Background: 15% opacity tint of the status color (`/15` Tailwind opacity modifier)
- No border, no shadow

### 2. `<MatchRow>`
- Layout: horizontal flex, single line, `flex items-center gap-4 px-4`
- Height: min 44px (`min-h-[44px]`)
- Background: transparent default; `bg-gray-900` on hover (`hover:bg-gray-900`)
- Cursor: `cursor-pointer` (entire row is clickable link)
- Divider: `border-b border-gray-800` between rows
- Column order (left to right):
  1. Team names: "Radiant Team vs Dire Team" — `text-white text-sm font-normal`, separator " vs " in `text-gray-500`
  2. Series score: e.g. "1-0 Bo3" — `text-gray-400 text-xs font-normal`
  3. Status tag: `<StatusTag>` component
  4. Game duration: "MM:SS" — `text-gray-400 text-xs font-normal`; hidden when `duration` absent (D-04)
- Right-align: series score + status tag + duration pushed to right with `ml-auto gap-3`
- Entire row wrapped in React Router `<Link to="/match/:matchId">` — `block` display

### 3. `<LeagueAccordion>`
- Header: `flex items-center justify-between px-4 py-2 bg-gray-900 cursor-pointer`
- Header typography: Heading (20px / 700) in `text-white` — `text-xl font-bold`
- Expand/collapse: chevron icon using plain Unicode `▾` / `▸` in `text-gray-400`; state managed via local `useState` (not URL — CONTEXT.md left this to discretion; URL state is over-engineered for this phase)
- Default state: expanded for all sections (D-07)
- Body: no background — inherits `bg-gray-950`; rows render directly under header
- Section spacing: `mb-4` between accordion sections

### 4. `<SkeletonRow>`
- Shown during initial data load only (before first successful fetch; subsequent 30s refreshes are silent per D-09)
- 5 skeleton rows rendered as placeholder
- Shape: same height as `<MatchRow>` (min 44px), animated pulse (`animate-pulse`)
- Color: `bg-gray-800` placeholder bars, `rounded` corners
- Two bars per row: wide bar (team names area) + narrow bar (tag area)

### 5. `<ErrorBanner>`
- Shown when Valve API is unreachable (initial load failure)
- Layout: full-width bar below page header, `p-4 bg-red-950 border border-red-800 text-red-300`
- No icon — text only (no icon library)
- Copy: see Copywriting Contract below

### 6. `<LastUpdatedBadge>`
- Placement: page header, trailing end (right side), vertically centered with page title
- Typography: Label (12px / 400) — `text-xs font-normal text-gray-400`
- Format: "Updated 2:41 PM" — time only, no date (D-10)
- Updates reactively after each successful TanStack Query fetch

### 7. Page Header
- Layout: `flex items-center justify-between px-8 py-6 border-b border-gray-800`
- Background: `bg-gray-950` (same as page — no elevated header surface)
- Left: page title "Dota 2 Match Analyst" — Display (28px / 700) `text-green-400 text-2xl font-bold`
- Right: `<LastUpdatedBadge>`

### 8. Match Detail Placeholder (`/match/:matchId`)
- Full-page `bg-gray-950 text-white p-8`
- Header: `<pre>` block with `bg-gray-900 rounded-lg p-6 overflow-auto text-sm text-gray-300 font-mono`
- Prominent dev label above pre block: "DEV PLACEHOLDER — Phase 3 will replace this" in `text-yellow-400 text-sm font-normal mb-4`
- JSON rendered via `JSON.stringify(matchData, null, 2)` (D-12)
- Back link: `<Link to="/">← Back to matches</Link>` — `text-green-400 text-sm hover:underline mb-6 inline-block`

## Interaction Contract

### Auto-refresh (D-09)
- TanStack Query `refetchInterval: 30000` — silent background refetch, no spinner, no row flash
- Stale data remains visible during refetch (no blank/loading overlay)
- `<LastUpdatedBadge>` updates timestamp only after successful fetch (use `onSuccess` / query observer)

### Row click navigation (D-11)
- Entire `<MatchRow>` is a `<Link>` component (React Router v7)
- Navigation target: `/match/:matchId` where `matchId` is the Valve `match_id` field
- No separate click handler — `<Link>` handles keyboard and pointer

### Accordion (D-07)
- All sections expanded on initial render (`useState(true)` default)
- Click header to toggle — local component state only
- No animation on expand/collapse (Phase 2 scope — keep simple)

### Loading states
- **Initial load:** Render 5 `<SkeletonRow>` components while query is in `isLoading` state
- **Subsequent refetches:** No visual change — data stays visible (`isPending` is false after first load)
- **Error (initial):** Show `<ErrorBanner>` in place of match list
- **Error (refetch):** Silently ignore — stale data stays visible. Timestamp does not update.

### Empty state
- Condition: fetch succeeds but returns zero live matches
- Render below header in place of accordion list (see Copywriting Contract)

## Accessibility Notes

Desktop-first per REQUIREMENTS.md. Minimum touch-target compliance (44px rows) applied as good practice even on desktop.

- All `<Link>` elements are keyboard-navigable (browser default)
- Status tags use text labels only — not color alone (tag text is the signal, color is secondary)
- Accordion headers are `<button>` elements (keyboard togglable)
- `<pre>` on placeholder page uses `overflow-auto` to prevent horizontal scroll breaking layout
