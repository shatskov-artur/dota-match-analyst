|----------|-------------|
| Valve API player data → React component render | Player name, hero name rendered as React text nodes — no dangerouslySetInnerHTML |
| hero portrait URL → img src | Portrait URL comes from heroes.json (static bundled data), not from Valve API response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering / XSS | PlayerRow team name / player name display | accept | React renders string values as text nodes by default; no dangerouslySetInnerHTML; any Valve API string is safely escaped by React's renderer |
| T-03-07 | Tampering | hero portrait img src | accept | src comes from heroes.json (static bundle built by Vite — not from API response); no user-controlled input reaches img src |
| T-03-08 | Information Disclosure | hidden profile player data | mitigate | hiddenProfile() guard applied at PlayerRow — hidden profiles show Valve name + portrait + KDA only; no OpenDota stats requested or rendered per D-07 |
