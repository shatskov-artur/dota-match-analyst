# Sketch 003: Home Redesign (dark esports)

## Design Question
The current site is already dark but flat (near-black `#0a0a0a`, hairline borders, no accents
except team colors) — and the user wants it fully replaced. Which dark **esports** theme feels
right when applied to the real Home screen (header + league accordion + match rows)?

## How to View
```
open .planning/sketches/003-home-redesign/index.html
```
Use the **Theme** dropdown in the top toolbar to switch between the three directions live.
All three render the exact same screen and real-ish data — only the visual system changes.

## Variants (10 dark themes — switch via dropdown, "Next ▸" button, or ← → arrows)
- **A: Broadcast Neon** — deep navy/graphite, neon cyan/magenta, glowing card edges, Rajdhani
  display type. Official Dota broadcast overlay.
- **B: Tactical Slate** — warm charcoal, muted gold + steel-blue, soft-shadow rounded cards, Inter,
  readability-first. Premium analytics dashboard (closer to Stratz).
- **C: Carbon Esports** — textured carbon, sharp clipped-corner cards, amber/electric-blue,
  Chakra Petch + mono numerics. Hard tournament HUD.
- **D: Cyber Purple** — violet/indigo base, vaporwave purple + teal neon glow. Synthwave esports.
- **E: Midnight Blue** — calm deep navy, single ice-blue accent, restrained. Quiet pro broadcast,
  easy on the eyes for long sessions.
- **F: Blood Dire** — near-black with crimson undertone, aggressive red + ember accents, angular
  cards. Maximum-intensity danger HUD.
- **G: Emerald Radiant** — forest-black with emerald + lime accents, jade glow. Fresh, growth,
  momentum — the radiant-side counterpart.
- **H: Mono Noir** — pure grayscale, zero hue except team red/green, hairline borders, mono type,
  zero rounding. Brutalist infosec terminal taken all the way.
- **I: Aurora Frost** — cool dark teal-slate with glassmorphism, frosted translucent cards, aurora
  gradient glow (teal→indigo). Modern, airy, premium.
- **J: Molten Gold** — espresso-black with warm gold/bronze accents, luxe championship feel. Premium
  without being loud.

## What to Look For
- **Overall vibe** — which one do you *want* to keep looking at for hours of viewing?
- **Card style** — glowing edges (A) vs soft rounded shadow (B) vs sharp angular clip (C)
- **Accent color** — cyan/magenta vs gold/steel vs amber/electric-blue (team red/green stay constant)
- **Typography** — display-heavy condensed (A/C) vs clean neutral (B)
- **Scannability** — can you read 7 matches across 2 leagues in one glance?

You can also cherry-pick: e.g. "B's palette but A's glowing hover bar."
